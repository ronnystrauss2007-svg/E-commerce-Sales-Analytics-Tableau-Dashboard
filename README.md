# 🛒 E-commerce Sales Analytics & Tableau Dashboard

An end-to-end sales performance analytics project using SQL for data extraction and aggregation, combined with an interactive Tableau dashboard to deliver actionable business insights.

---

## 📌 Interactive Dashboard
🔗 [View Full Interactive Tableau Dashboard](https://public.tableau.com/app/profile/ronny.strauss/viz/E-CommerceAnalyticsExecutiveDashboard/E-CommerceExecutiveDashboards#1)

---

## 🛠️ Tech Stack
* **Database:** Microsoft SQL Server (T-SQL)
* **Visualization:** Tableau Public
* **Data Source:** Raw E-commerce transactional records (`ecommerce_raw.csv`)

---

## 📁 Repository Structure
* **`ecommerce_raw.csv`** – Transactional dataset including orders, sales, customer, and regional metrics.
* **`sales_analysis.sql`** – SQL queries for database creation, bulk insert, revenue aggregation, profit margins, and regional sales performance.

---

## 📊 Key Insights & Analytics
1. **Revenue & Profitability:** Tracking total sales volume, average order value (AOV), and overall profit margins.
2. **Regional Performance:** Mapping top-performing geographical markets and customer segments.
3. **Category Breakdown:** Analyzing high-margin vs. low-margin product categories to optimize inventory focus.
